# CovelliteAI Assets

## `covelliteai_skin.png`

Provided player skin.

- 64×64 PNG, 32-bit ARGB (Minecraft 1.21 format)
- Hooded dark outfit with violet accents and glowing violet eyes
- Use the model type (classic/slim) that matches how the account is registered

The mod does not force the skin onto an account. Apply it to the AI account
through the launcher or the server's skin system.
